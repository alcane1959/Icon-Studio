# Icon Studio

Um editor de ícones online desenvolvido em HTML, CSS e JavaScript puro. Permite criar, editar, importar e exportar ícones em diversos formatos diretamente no navegador, sem necessidade de instalação.

## ✨ Recursos

### Ferramentas de desenho
- ✏️ Lápis
- 🧽 Borracha
- 🪣 Balde de preenchimento
- 🎯 Pipeta
- 📏 Linha
- ▭ Retângulo
- ⭕ Elipse
- 🖼️ Seleção
- ✋ Mover seleção

### Camadas
- Criar múltiplas camadas
- Duplicar camadas
- Reordenar camadas
- Ajustar opacidade
- Mostrar/Ocultar camadas
- Renomear camadas

### Edição
- Desfazer e refazer alterações
- Copiar, recortar e colar seleções
- Redimensionar documento
- Remoção automática de fundo
- Captura de cores da tela (EyeDropper API)
- Paleta de cores personalizada
- Controle de transparência (Alpha)

### Exportação
- PNG
- ICO (múltiplos tamanhos)
- SVG
- WebP
- BMP

### Projeto
- Salvar projetos no formato `.iconproj`
- Abrir projetos salvos
- Importar imagens externas
- Arrastar e soltar imagens diretamente na área de trabalho

## 🚀 Como usar

1. Abra o arquivo `index.html` em qualquer navegador moderno.
2. Escolha uma ferramenta na barra lateral esquerda.
3. Desenhe no canvas central.
4. Gerencie camadas na barra lateral direita.
5. Exporte o resultado no formato desejado.

## 🎨 Recursos Visuais

- Tema claro e escuro
- Grade opcional para pixel art
- Controle de zoom de 2x a 40x
- Pré-visualização automática em múltiplos tamanhos
- Fundo quadriculado para visualizar transparência
- Painéis laterais redimensionáveis

## 📦 Formato ICO

O exportador ICO permite gerar ícones contendo múltiplas resoluções simultaneamente:

- 16×16
- 24×24
- 32×32
- 48×48
- 64×64
- 128×128
- 256×256

## 🌐 Compatibilidade

Funciona nos principais navegadores modernos:

- Google Chrome
- Microsoft Edge
- Firefox
- Opera

> A funcionalidade "Capturar cor da tela" depende da API EyeDropper e pode não estar disponível em todos os navegadores.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript ES6+
- Canvas API
- File API
- EyeDropper API
- Drag and Drop API
